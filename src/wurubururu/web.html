    Gmail · 캘린더

    Google 계정에 읽기 전용으로 연결합니다. 비밀번호는 저장하지 않습니다.

    처음 한 번: OAuth 클라이언트 만들기 (약 10분)
    1. Google Cloud 콘솔에서 새 프로젝트를 만듭니다. 이름은 아무거나(예: wurubururu).
    2. Gmail API와 Google Calendar API를 각각 열어 사용을 누릅니다.
    3. Google 인증 플랫폼에서 시작하기 → 앱 이름 입력, 대상은 외부, 연락처에 본인 메일을 넣고 만듭니다.
    4. 대상 메뉴에서 앱 게시를 눌러 게시 상태를 프로덕션으로 바꿉니다. 테스트 상태로 두면 7일마다 다시 로그인해야 합니다. 검증은 신청하지 않아도 됩니다.
    5. 클라이언트 메뉴에서 클라이언트 만들기 → 유형 데스크톱 앱 → 만든 뒤 JSON 다운로드.
    6. 아래 클라이언트 파일 올리기로 그 JSON을 고르고, Google로 로그인을 누릅니다.
    7. 로그인 화면에 "확인되지 않은 앱"이 나오면 고급 → (앱 이름)(으)로 이동을 누릅니다. 본인이 만든 앱이라 안전합니다.
